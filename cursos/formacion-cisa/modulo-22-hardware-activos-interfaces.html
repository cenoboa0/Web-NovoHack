Hardware, gestión de activos e interfaces del sistema

El Dominio 4 abre con los cimientos físicos y lógicos de las operaciones de TI: los componentes de hardware que soportan el procesamiento de la empresa, el inventario que permite gestionarlos como activos y las interfaces que conectan sistemas entre sí. Este módulo también introduce el patrón que vas a ver una y otra vez en el Dominio 4: cada elemento de la infraestructura trae consigo un riesgo de seguridad y de control que el auditor de SI debe saber identificar.

≈15 min de lectura Hardware, activos de TI e interfaces

1 Componentes y arquitecturas de hardware de computadora

Las organizaciones dependen de una variedad de dispositivos de procesamiento que cumplen funciones específicas dentro de la infraestructura de TI. Los dispositivos de procesamiento comunes de la empresa incluyen:

  • Servidores de impresoras.
  • Servidores de archivos.
  • Servidores de aplicaciones (programas).
  • Servidores web.
  • Servidor de proxy.
  • Servidor de base de datos.
  • Servidores de bases de datos (en configuraciones distribuidas o replicadas).

Riesgos relacionados con los dispositivos USB

Los dispositivos de almacenamiento portátiles, como las memorias USB, introducen riesgos particulares porque combinan capacidad de almacenamiento con facilidad para salir del perímetro de la organización sin control:

Virus y otro software malicioso

Un USB puede introducir código malicioso directamente en la red interna, evitando controles perimetrales.

Hurto de datos

Su tamaño y portabilidad facilitan la copia y sustracción de información sensible.

Pérdida de datos y medios

Al ser pequeños, se extravían con facilidad, junto con toda la información que contienen.

Corrupción de datos

Un uso o manejo inadecuado puede dañar la integridad de los datos almacenados.

Pérdida de confidencialidad

Sin cifrado, cualquier persona que encuentre el dispositivo puede acceder a su contenido.

2 Gestión de activos de TI

El primer paso en la gestión de activos de TI es el proceso de identificar y crear un inventario de activos de TI, tanto para software como para hardware. El registro de inventario de cada activo de información debe incluir:

  • El propietario.
  • Custodio designado.
  • Identificación específica del activo.
  • Valor relativo para la organización.
  • Implicaciones de pérdida y prioridad de recuperación.
  • Ubicación.
  • Seguridad/clasificación de riesgos.
  • Grupo de activos (cuando el activo forma parte de un sistema más grande de información).
Para el examen: un inventario de activos incompleto o desactualizado compromete prácticamente todos los demás procesos de este dominio —desde la gestión de cambios hasta la continuidad del negocio— porque no se puede proteger, recuperar o dar prioridad a lo que no está identificado.

3 Interfaces del sistema

Las interfaces del sistema permiten el intercambio de datos entre aplicaciones, plataformas u organizaciones distintas. El riesgo asociado con las interfaces de sistema se agrupa en cuatro áreas:

Integridad del intercambio de datos

Que los datos transferidos entre sistemas lleguen completos y sin alteraciones.

Seguridad de los datos

Que la información esté protegida durante la transferencia frente a accesos no autorizados.

Privacidad

Que el intercambio respete las restricciones sobre el uso de datos personales o sensibles.

Legal

Que la transferencia cumpla con las obligaciones contractuales y normativas aplicables.

Problemas de seguridad de las interfaces de sistema

  • Las transferencias de datos seguras garantizan la integridad de los datos.
  • Las transferencias de datos seguras garantizan la confidencialidad y la protección de los datos frente a: acceso no autorizado mediante interceptación, actividad maliciosa, y errores u otros medios.
  • La disponibilidad de las interfaces del sistema repercute directamente en la fiabilidad de los datos: si la interfaz falla, los sistemas que dependen de ella pueden operar con información desactualizada o incompleta.
